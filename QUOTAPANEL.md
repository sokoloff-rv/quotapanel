# QuotaPanel — квоты слева на панели задач Windows

Локальная версия на основе QuotaBubble (MIT), исходный коммит
`d7fe6e4dfc36e957f927fb0482fd421988bf3a3b`, релиз провайдеров `v0.2.5`.

## Запуск

Распакуйте Windows-архив целиком в постоянную папку и запустите `QuotaPanel.exe`.
Папка `_internal` должна оставаться рядом с приложением. Python устанавливать
не нужно. Для просмотра примера без чтения токенов запустите `Пример.cmd`.

Панель показывает Codex и Claude, по две квоты: 5 часов и 7 дней.
Проценты означают **оставшийся** лимит, рядом — отсчёт до сброса (`(2ч 14м)`).
Зелёный цвет — осталось больше 25%, жёлтый — 11–25%, красный — 10% и меньше.
Точка рядом с процентом означает
сохранённые данные: последняя попытка обновления не удалась или приложение
только запущено. Если данных нет, выводится прочерк либо пояснение, а не 0%.

Левый клик открывает подробности и время сброса. Правый клик — обновление и
настройки. Значок в трее позволяет изменить ширину, отступ слева (от 0)
и интервал обновления квот (1–60 минут), скрыть панель, включить автозапуск и выйти.
По умолчанию обновление — каждые 5 минут. Настройки сохраняются,
новый интервал применяется без перезапуска. Отсчёт до сброса лимита
перерисовывается отдельно, каждые 15 секунд.

В настройках можно выбрать тему компактной панели: «Как в Windows», «Тёмная»
или «Светлая». «Прозрачный фон» убирает её подложку, сохраняя цвета текста
из выбранной темы. Эти настройки тоже сохраняются и применяются сразу.
Прозрачная панель принимает клики по всей площади, включая пустые участки.
Оба контекстных меню используют компактные отступы.

Для работы нужно войти в Codex и Claude Code на этом Windows-компьютере.
Codex читается из `%USERPROFILE%\.codex\auth.json` (учитывается `CODEX_HOME`),
Claude — из `%USERPROFILE%\.claude\.credentials.json`. Вход только в веб-версию
Claude не создаёт нужный файл. Приложение не предлагает вводить API-ключи,
не обновляет токены, не копирует их в настройки или кеш и не меняет файлы входа.
Квоты запрашиваются напрямую по HTTPS у `chatgpt.com` и `api.anthropic.com`.

## Положение и ограничения прототипа

Окно QuotaPanel закрепляется внутри свободной левой части панели задач Windows
и остаётся с ней при открытии «Пуска». Приложение работает в своём процессе
и не загружает код в Explorer. Системные мини-приложения оно не заменяет.
Нужна нижняя горизонтальная панель задач с кнопками по центру. Если кнопки
выровнены слева, QuotaPanel скрывается, чтобы не перекрыть «Пуск».
При полноэкранном приложении панель скрывается, после выхода появляется снова.
При перезапуске Explorer положение перечитывается автоматически.
Если приложение запускается при уже открытом «Пуске», закрепление откладывается
до возвращения панели задач в обычное состояние (после клика по рабочему столу
или другому приложению).

Панель не резервирует место: если закреплённые приложения приблизятся к ней,
уменьшите ширину. Системную погоду в этой области при необходимости отключите
в «Параметры → Персонализация → Панель задач → Мини-приложения».
Поддерживается основная панель задач, а не одновременное отображение на всех
мониторах. При автоскрытии QuotaPanel отображается над открытой панелью задач;
это предварительная поддержка, не проверенная на всех конфигурациях Windows.

Настройки, кеш квот и скрывающие секреты журналы находятся в
`%LOCALAPPDATA%\QuotaPanel`. Автозапуск выключен по умолчанию. Чтобы удалить
приложение, сначала отключите автозапуск в меню, выйдите и удалите папку.
Приложение не подписано цифровой подписью.

## Сборка из исходников

Python 3.11 или новее и uv:

```powershell
uv sync --locked
uv run python -m quotabubble.app.taskbar_main --demo
uv run ruff check src tests
uv run pytest -q
uv run pyinstaller --noconfirm packaging/quotapanel.windows.spec
```

Готовая папка — `dist/QuotaPanel`. Для обычного запуска из исходников уберите
`--demo`. Отдельная точка входа — `quota-panel`. Исходное приложение
`quotabubble` сохранено для сравнения; его настройки не используются QuotaPanel.
